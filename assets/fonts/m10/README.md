# Local fonts for M10

All files are bundled locally; the application makes no font-service requests.
Noto Sans Arabic / Japanese / Korean / Simplified Chinese: Google Fonts upstream,
SIL Open Font License 1.1. The matching OFL files contain copyright and license.
Sources: https://github.com/google/fonts/tree/main/ofl/notosansarabic
https://github.com/google/fonts/tree/main/ofl/notosansjp
https://github.com/google/fonts/tree/main/ofl/notosanskr
https://github.com/google/fonts/tree/main/ofl/notosanssc

Monocraft: Idrees Hassan, OFL 1.1 (Monocraft-OFL.txt).
Source: https://github.com/IdreesInc/Monocraft
https://github.com/IdreesInc/Monocraft/blob/main/dist/Monocraft-ttf/Monocraft.ttf
The author's redraw includes SGA letters U+EB40–U+EB59, mapped from A–Z.
No original Minecraft assets or uncleared SGA font files are included.

Downloaded from the official repositories on 24 October 2026. No fonts installed
on the operating system. Original font files and corresponding licenses retained.
