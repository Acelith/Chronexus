# Dragon Circle local assets

Created on October 24 2026 with the imagegen skill (integrated tool):

- dragons.webp: two bronze dragons form the circle, transparent center.
- fire.webp: transparent flame used only in the landing phase.
- material.webp: dark stone and engraved bronze for the dice faces.

Originals stored in the Codex generated_images directory; working copies
in .tools/m9 (ignored). WebP conversion with ffmpeg, alpha preserved for dragons
and flames, material at 384 px and illustrations at 1024 px. Approximately 0,5 MB total.
Geometries, numbers, and results are rendered by the code, never from the image.
All assets are included in the bundle and work offline. No campaign data
sent to generate them, no generation or remote request at the turn.
