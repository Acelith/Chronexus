# Trust and transparency (M33)

Chronexus is written largely by AI agents. This page lists what can leave your computer,
what never does, the threats considered, and how to check a release yourself. The host
table is checked against the code by `node scripts/trust/check-network.mjs` (CI fails if a
host is added to the code without being listed here, or listed here without being in the
code).

## What can leave the computer

Every request is HTTPS (except loopback), started by an explicit action unless noted, sends
no campaign content unless you chose to share it, and has bounded size and time.

| Host | When | What is sent |
| --- | --- | --- |
| `github.com` | Update check at startup (once per session, **on by default**, can be turned off in App settings → App updates) and on request; download of the pinned Ollama 0.40.10 archive when you install AI components | Anonymous GET of `latest.json` / release files; nothing about you or your campaigns |
| `api.github.com` | Only for a custom update channel on GitHub you set yourself | Anonymous GET |
| `release-assets.githubusercontent.com` | Redirect target of the two downloads above | Anonymous GET; other redirect hosts are refused |
| `objects.githubusercontent.com` | Older redirect target of the Ollama archive download | Anonymous GET; the archive's SHA-256 is pinned |
| `dnd5e.wikidot.com` | You open a page in the D&D wiki (Wikidot provider) | GET of an allowlisted public page; no cookies, keys or campaign data |
| `api.open5e.com` | You search the Open5e wiki | Only the typed rules term and entry IDs |
| `www.dnd5eapi.co` | You browse or import from the SRD 2014 catalog | GET of allowlisted SRD collections |
| `127.0.0.1` | Local AI, when you enable it | Prompts and selected notes to the Ollama runtime on this computer only; the app checks that its cloud features are off first |

Not in the code, but reachable on your explicit request:

- **Your sharing server** (M24/M25): the HTTPS origin you configure. Only items you mark
  *private* (your own devices) or *shared* (campaign members) are uploaded; the server operator
  can read them (no end-to-end encryption). The session token stays in `sync-account.json`.
- **The Ollama model registry**: when you pull a qualified model in App settings, the local
  Ollama runtime downloads it; Chronexus then checks the weight digest.

## What never leaves

Notes, Codex pages, sheets, clues, AI conversations, training data, backups, images and
preferences stay local unless an item is explicitly shared as above. There is no telemetry,
no account requirement and no automatic upload. Diagnostic reports are not sent by the app.

## Threats considered

| Threat | Mitigation | Limit |
| --- | --- | --- |
| Tampered update | Tauri updater requires a minisign signature from the pinned key in `tauri.conf.json`; a backup is made before installing | Unsigned pre-releases (macOS/Linux) are not offered by the updater; verify them by checksum |
| Compromised download host / redirect | HTTPS only, redirect host allowlists, SHA-256 pinned for Ollama | A compromised GitHub account can publish files; the signing key is kept offline |
| Malicious wiki page or imported archive | Parsed into inert text; scripts, configuration and instructions are never executed | Text you import is still shown as written |
| Prompt injection via notes into the AI | Sources are data, citations are verified, instruction-like items are excluded on the server | A local model can still produce wrong answers; they are drafts |
| Malicious image | Only PNG/JPEG/WebP with size, dimension and decode bounds | — |
| Sharing server operator | Only chosen items are uploaded; the demo campaign cannot be shared | No end-to-end encryption |
| Someone with access to your disk | — | The archive is **not encrypted at rest**; use OS disk encryption |
| Vulnerable dependency | Lockfiles; CI runs `cargo audit` and `pnpm audit --prod`; SBOM and licence report per release | Advisories are only as current as the databases |

## Supply chain

- Each release can carry `chronexus-VERSION-sbom.cdx.json` (CycloneDX 1.5) and
  `chronexus-VERSION-licenses.md`, generated by `scripts/release/sbom.py` from the tagged
  lockfiles: `publish_unsigned.py` attaches them automatically; signed releases get them with
  `attach_sbom.py` after finalization. Dependencies under MPL-2.0 (BlockNote, cssparser,
  selectors) are listed for review in the report.
- Check a download: see [Verify your download](wiki/Verify-Your-Download.md).
- Rebuild it yourself: see [Reproducible builds](REPRODUCIBLE_BUILDS.md).
