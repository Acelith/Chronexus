# Chronexus Table

In the campaign overview, load Tables explicitly, join with the GM's invitation
code, and open a table beside your journal. Link it to this campaign if desired.
The journal remains usable when the table disconnects; movement pauses until the
server reconnects. Closing the table stops its live connection.

Select your token below the map and move with arrows, drag it, or use position
fields. Ruler, area templates and the converter show feet and metres with the
chosen conversion convention. Initiative, HP, conditions and rolls affect table
tokens. They do not change your local character sheet automatically.

Character projection lets you review and confirm selected name, HP/AC, portrait
and manual speed. Nothing is selected by default. Applying token HP to the local
sheet is a separate confirmed action. Notes and resources never accompany this copy.

The GM prepares scenes, fog, walls, monsters, encounters and artwork in the server
web interface. Its image library supports computer PNG/JPEG/WebP import and explicit
licensed Wikimedia Commons searches/imports. The server filters hidden information
before sending it to players. Fog uses a coarse visibility mask, not pixel precision.

GM journal access is granted per selected already shared/synchronized item and can
be revoked. Table snapshots are transient; backups retain only your local journal
and table association identifiers. Windows source/build checks passed; physical
cross-platform and production-network qualification remain pending.
