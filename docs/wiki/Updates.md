# Updates

## The herald

At each launch Chronexus asks the release channel, once, whether a newer version exists.
If so — and only when you are not busy writing — a herald with a trumpet presents what
is new.

- **Update** starts the verified download.
- **Remind me later** postpones; **Ignore this version** stops announcing it.
- The sound and the startup check itself can be turned off in **App settings → App
  updates**. You can always check manually there.

## Installing safely

1. The download is verified with Chronexus's own cryptographic signature; anything that
   does not match is refused.
2. Before installing, Chronexus creates and verifies a **full backup** in
   `Documents/Chronexus/Backup aggiornamenti` (or the data folder, with a notice). If the
   backup fails, the installation does not start.
3. Installation starts only after **Create backup and install**.

Update backups are never deleted automatically.
