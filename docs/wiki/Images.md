# Images

Codex pages, the character sheet, inventory items and abilities can hold images:
portraits, maps, handouts, references.

- Formats: PNG, JPEG, WebP. Limits: 20 MiB, 8192 pixels per side, 32 million pixels.
- Chronexus keeps **its own copy** of the file inside the archive. Moving or deleting the
  original afterwards changes nothing.
- Each image has a caption and a role (for a map, use a Place page and the *Map* role).
  Previews and zoom work offline.
- Images are included in backups and verified with checksums.
- **Remove from entry** unlinks the image but keeps the file, so it can be recovered.
