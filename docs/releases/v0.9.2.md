# Chronexus 0.9.2 — A Chronexus-branded Windows installer

The Windows installer now carries the user-selected Chronexus artwork: the herald
and wordmark on welcome/finish pages, a compact wordmark on the wizard headers,
and the Chronexus icon for installer and uninstaller. The sidebar uses the app's
leather, brass and burgundy palette. Labels and controls remain native, readable
text; the standard installation, upgrade and cancellation flows are preserved.
The passive in-app updater may omit wizard pages as before.

Includes the 0.9.1 fixes for existing-archive backup verification and startup update
checks. Existing archives migrate automatically to schema 021. If an older installed
updater is blocked by the backup error, preserve a verified backup, close Chronexus
and run this installer manually. No new schema, app identifier or signing key.

Windows x64 app only, with the production updater signature, without AI weights or
Windows Authenticode signing. Other platforms/architectures and actual installation
or upgrade remain unverified. Published older installers are not replaced.

Verified on Windows x64: signed NSIS and frontend build, production package signature
and tamper rejection, all 27 release-tool tests, correct bitmap dimensions/format,
and the actual welcome/directory wizard pages with native accessible headings and
controls. The wizard was cancelled before installation. Source artwork unchanged.
