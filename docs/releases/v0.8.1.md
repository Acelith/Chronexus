# Chronexus 0.8.1 — English-first internationalization (unreleased)

English is now the primary interface, source and fallback language for new
profiles. Italian remains available, and existing language preferences are
preserved. Earlier archives without a saved choice retain their Italian
experience. Language recovery always offers English in ordinary readable text.

- English app/package metadata, developer diagnostics and public documentation.
- English README, with an optional Italian version and English public screenshots.
- English AGENTS instructions, commit conventions, MCP guidance and AI prompts.
- The local assistant answers in the selected supported language, defaulting to
  English. Training examples use English wrapper text and preserve quoted sources.
- Stable message IDs and legacy Italian diagnostic aliases; honest fallback for
  newly catalogued messages that other locales do not yet translate.
- Existing campaign text, archived answers, UUIDs, schema 018, backup folder names
  and legacy app identifiers remain intact. Cargo license metadata now matches
  the repository's existing Apache-2.0 license.

No new installer or public release has been produced for this source change.
The published channel remains 0.8.0. Native Windows checks cover fresh English
startup, persisted Italian, English recovery and real Qwen English/Italian answers.
Other operating systems, installation/upgrade and complete linguistic review
remain pending. See STATUS for actual automated validation results.
