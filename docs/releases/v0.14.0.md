# Chronexus 0.14.0 — Windows x64

A GM can now run their own table from the desktop app, the way it works in Roll20.
Open a table you created as GM and the Scenes, Fog and Library tabs appear beside
the map:

- **Maps in one step:** drop a PNG, JPEG or WebP map on the board, or upload it from
  the Scenes tab, and it becomes a scene at the image size. Universal VTT files keep
  working. Players see a scene only after you activate it.
- **NPC tokens by click:** choose a saved monster or a library image, click the cells
  where it goes and press Esc when done (Enter places it at the map centre). Monster
  tokens keep private HP/AC and the stat block as your note.
- **Token catalog:** search game-icons.net icons (CC BY 3.0, a few CC0) for round,
  coloured NPC tokens, Wikimedia Commons images with open licences, or SRD 2014
  monsters. Searches send only the term you type, through your Chronexus Server;
  author and licence stay attached to every imported image.
- The status line under the map is readable again on the dark board.

GM tools need Chronexus Server 0.3.0. Players keep the same view as in 0.13.

This package is for Windows x64 only. The NSIS installer has a production Tauri
updater signature and is available through the in-app updater with its required
backup. It has no Windows Authenticode signature, so SmartScreen may warn on first
launch. It contains no AI model weights. Windows ARM64, macOS and Linux packages
have not been built for this version.

No database migration. Table data stays on the server and out of local backups.
Existing campaigns, saved interface language, notes, attachments and local AI
choices are preserved.
