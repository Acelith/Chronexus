# Chronexus 0.8.0 — Periodic backups, AI-guided, and new herald

**Backups in Documents (M19).** In App Settings → Backup, you can enable
periodic backups (every day, every week, or every N hours) that start only when
the app is open and idle, never while you are typing. Copies go to
`Documenti/Chronexus/Backup periodici` or into a folder chosen by the system selector; Chronexus keeps the specified number of copies and deletes only those
 ]
that he created and registered with a hash. They are deactivated until you turn them on: the
file `.nodex` is not encrypted and Documents can be synchronized in the cloud.

- Backups before updates go to `Documents/Chronexus/Backup
updates`; if the Documents are unusable, they remain in the data folder
with a warning. If the backup fails, the installation does not start.
- Backup and restore lists the folder backups with type, date, and size and
copies old update backups into Documents with SHA-256 verification.

**Local AI from settings (M22).** Component check, guided installation
of Ollama 0.40.10 from the official archive with verified SHA-256, explicit start and
stop, and download of only qualified models (Qwen3.8-27B, Gemma 4
12B) with weight verification. No download at startup, no cloud service.

**Visual identity (M21) and README (M20). Heraldic icon and logo, project presentation
renewed in Italian and English with screenshots of an invented campaign.

Verifications: 134 Rust test and 332 frontend test, Clippy, lint, TypeScript and testing
on Windows desktop on isolated profiles (automatic backups, rotation, resume after
reboot, restoration with images; real installation of Ollama and verification of
Gemma weights). Not verified: macOS/Linux, full disk and physical read-only
folders, complete download of 17,7 GB of Qwen3.8-27B from the interface,
upgrade installed from a previous version. The new screens are
only in Italian even in other languages.

SQLite schema unchanged (018). The updater verifies the signature and creates a backup before
installation. The installer is not Authenticode signed: Windows may show
SmartScreen. No AI weights, personal data or secrets are included in the package.
