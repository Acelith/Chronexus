# Chronexus 0.13.0 — Windows x64

This version brings Chronexus Table to the desktop. Join a table with your GM's
invitation code and play beside your journal: move your token on the map, measure
in feet and metres, follow initiative, roll dice in the table chat (`/r 1d20+5`,
`/r 2d20kh1`, `/gr` secret rolls, `/w gm` whispers) and ping the map. The table
needs Chronexus Server 0.2.0; your GM prepares maps, fog, monsters and encounters
in the server's web interface. Table state is never stored in your local backups,
and nothing from the table changes your character sheet unless you confirm it.

Also new since 0.12.0:

- First-start tour and a removable demo campaign.
- A Trust page showing every data flow, with supply-chain checks.
- Local diagnostic report preview and save, with no automatic upload.
- Imports from Obsidian, Logseq, Kanka and D&D character files, with preview.
- World calendar and campaign timeline; pins and routes on map images.
- Session recap and printable layouts for sessions, Codex pages and the character.
- Manual Fate Core and Fate Accelerated sheet presets.

This package is for Windows x64 only. The NSIS installer has a production Tauri
updater signature and is available through the in-app updater with its required
backup. It has no Windows Authenticode signature, so SmartScreen may warn on first
launch. It contains no AI model weights. Windows ARM64, macOS and Linux packages
have not been built for this version.

Database migrations are additive. Existing campaigns, saved interface language,
notes, attachments and local AI choices are preserved.
