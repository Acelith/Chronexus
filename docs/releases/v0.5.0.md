# Chronexus 0.5.0 — Wiki Wikidot and Update Herald

- **D&D Sources / Wiki** in the app settings: Wikidot D&D 5e (default)
  or Open5e. With Wikidot, the public index of the category and the name
  are searched on the device; plain text entries with declared source, origin
  (published, Unearthed Arcana, homebrew), URL, and page license.
- If Wikidot does not provide information, Chronexus asks whether to use Open5e; without
  your consent, it does not contact the other source.
- **Clear offline cache** for a source or for all wikis, with confirmation. Campaigns,
  imported spells, images, backups, and the chosen source remain intact.
- Wikidot spells importable into the sheet with an editable module and
  preserved provenance.
- **Update Herald**: a light check at startup (at most every
  20 hours, can be disabled) announces new versions with a trumpet and manifesto,
  only when the app is inactive. «Update» downloads and verifies; the installation
  remains explicit, always after the mandatory backup.

Compatibility: SQLite database **016** (additive migration). Backups created with
0.5.0 are not restored with 0.4.0. From 0.4.0, the update is available
in the app settings with automatic backup. Separate AI runtime/weights.

Verifications and limits: docs/STATUS.md. Windows x64 only; updater signature distinct from
Authenticode. New interface text in Italian in other languages.
