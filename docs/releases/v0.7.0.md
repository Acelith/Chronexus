# Chronexus 0.7.0 — Qwen3.8-27B locale, Gemma secondaria

The assistant and the wiki translation propose Qwen3.8-27B as the primary model.
Gemma 4 12B remains an explicit faster alternative and preserves the training
campaign locale. The qualified 27B model uses both GPU and RAM on the
RTX 4080 SUPER from 16 GB; no external AI services or automatic downloads.

- Qualified choices and weights shared between assistant, wiki, and local tools.
- Qwen/Gemma selector for translations, without automatic model changes.
- 018 Schema: old Qwen disabled, history and citations preserved.
  Previous backups restorable; a new choice and explicit activation are required.
- Retraining available only with Gemma, with an explanation for Qwen.
- Withdraw scripts that built new installers for the old Qwen.

Installer **Windows x64**, app only. Runtime and AI weights separated:
`ollama pull qwen3.8:27b-q4_K_M`, or already qualified Gemma. Preparation,
digest and requirements in `docs/AI_MODELS.md`. No specialized D&D model.
Translations are drafts to be compared with the original; names and terms may
be imprecise. No automatic modification of notes, cards, or facts.

Real qualification: 35/35 comparison and 40/40 desktop benchmark for each model,
017 backup restored without loss, cache reread with runtime off.
162 frontend test, 118 ordinary Rust tests, Clippy, lint, TypeScript, i18n,
scripts and Windows builds verified. Other GPU/macOS/Linux and real installation
remain to be tested; no physical offline proof declared.

The updater verifies the signature and requires a valid backup before installation.
The installer is not Authenticode signed: Windows may show SmartScreen.
No AI weights, personal data, or secrets are included in the package.
