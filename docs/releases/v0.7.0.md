# Chronexus 0.7.0 — Qwen3.8-27B locale, Gemma secondaria

L’assistente e la traduzione wiki propongono Qwen3.8-27B come modello principale.
Gemma 4 12B resta un’alternativa esplicita più rapida e conserva l’addestramento
locale della campagna. Il modello 27B qualificato usa insieme GPU e RAM sulla
RTX 4080 SUPER da 16 GB; nessun servizio AI esterno o download automatico.

- Scelte e pesi qualificati condivisi fra assistente, wiki e strumenti locali.
- Selettore Qwen/Gemma per le traduzioni, senza cambi automatici di modello.
- Schema 018: vecchi Qwen disabilitati, cronologia e citazioni conservate.
  Backup precedenti ripristinabili; serve una nuova scelta e attivazione esplicita.
- Riaddestramento disponibile soltanto con Gemma, con spiegazione per Qwen.
- Ritirati gli script che costruivano nuovi installer del vecchio Qwen.

Installer **Windows x64**, solo app. Runtime e pesi AI separati:
`ollama pull qwen3.8:27b-q4_K_M`, oppure Gemma già qualificata. Preparazione,
digest e requisiti in `docs/AI_MODELS.md`. Nessun modello D&D specializzato.
Le traduzioni sono bozze da confrontare con l’originale; nomi e termini possono
essere imprecisi. Nessuna modifica automatica a note, schede o fatti.

Qualifica reale: confronto 35/35 e benchmark desktop 40/40 per ciascun modello,
backup 017 ripristinato senza perdita, cache riletta con runtime spento.
162 test frontend, 118 test Rust ordinari, Clippy, lint, TypeScript, i18n,
script e build Windows verificati. Altre GPU/macOS/Linux e installazione reale
restano da collaudare; nessuna prova fisica offline dichiarata.

L’updater verifica la firma e richiede un backup valido prima dell’installazione.
L’installer non è firmato Authenticode: Windows può mostrare SmartScreen.
Nessun peso AI, dato personale o segreto è incluso nel pacchetto.
