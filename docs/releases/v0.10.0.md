# Chronexus 0.10.0 — macOS, Linux and campaign members (pre-release)

**First packages for macOS and Linux**, built in dedicated containers (Linux, Windows) and
natively (macOS). This is a **pre-release without signatures**: no Authenticode, no Apple
Developer ID and no updater signature. Installed 0.9.x copies keep receiving updates only from
signed releases, so this version is **not offered by the in-app updater**: download it here.
Every file is listed with its SHA-256 in `SHA256SUMS.txt`.

| System | File | Tested |
| --- | --- | --- |
| macOS Apple Silicon | `Chronexus_0.10.0_aarch64.dmg` | Installed from the DMG and started |
| macOS Intel | `Chronexus_0.10.0_x64.dmg` | Built; not started (no Intel Mac available) |
| Linux ARM64 | `Chronexus_0.10.0_arm64.deb`, `Chronexus_0.10.0_aarch64.AppImage` | Installed and started on Debian 12 and Ubuntu 24.04 |
| Linux x64 | `Chronexus_0.10.0_amd64.deb` | Installed and started on Ubuntu 24.04 (emulated) |
| Windows x64 | `Chronexus_0.10.0_x64-setup.exe` | Built; not run (no Windows machine available) |

Not available: Windows ARM64 (the cross-build fails in a cryptography library) and the
Linux x64 AppImage (needs a native x64 build host).

**First launch of an unsigned app**
- Windows: SmartScreen → *More info* → *Run anyway*.
- macOS: right-click the app → *Open* → *Open* (ad-hoc signed, not notarized).
- Linux: install the `.deb` with your package manager, or make the AppImage executable.

**New: campaign members.** In a shared campaign's *Sharing* view, *Members* lists who is in
the campaign (read from the server only when you ask). The owner switches members between
player and reader and removes members; players and readers can leave. Every removal is
confirmed first.

**Fixed**
- Your role in a shared campaign is read again at every synchronization: a player made reader
  no longer retries refused changes forever, and a reader made player can share again. A
  reader's unsent changes are shown as waiting, never as saved.
- macOS: the app bundle now carries a valid ad-hoc signature.
- Linux: the campaign picker in the sidebar is readable.

**Works with** Chronexus Server 0.1.0 and 0.1.1. No schema change (021); existing archives
open as before.

**Verified (27 October 2026):** 173 Rust tests and Clippy, 196 interface tests, TypeScript,
ESLint, the localization gate (1319 messages, ten languages); the client against the real
server binary (4 live tests); three apps (macOS and two Linux) against a Docker deployment over
HTTPS in a 37-step sharing scenario; the package installations listed above.
