# Chronexus 0.4.0 — internal updates

- App settings: explicit control of new versions, download
cancelable and installation with mandatory automatic backup.
- Public Forgegit channel via release API or configurable HTTPS manifest.
- Package and version signing, rejection of incomplete/tampered downloads,
no account or campaign content sent to the server.
- `.nodex` backup of all campaigns and managed attachments; received with hash
and preferences. If the backup fails, the installer does not start.
- Included external MCP integration of the 0.3.0, always hidden and disabled by
default; the integrated assistant remains excluded.

SQLite 015 and archive identifier unchanged. Separate AI runtime/weights.
Versions without an updater require this first manual installation;
subsequent versions can be installed by the app. Reopen upon completion.

Local checks and platform limits in docs/STATUS.md; procedure and signature in
docs/UPDATES.md. Updater signature distinct from Authenticode; the channel must not
announce macOS/Linux targets without having actually built and verified them.
