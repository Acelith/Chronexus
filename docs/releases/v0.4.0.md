# Chronexus 0.4.0 — aggiornamenti interni

- Impostazioni dell’app: controllo esplicito delle nuove versioni, download
  annullabile e installazione con backup automatico obbligatorio.
- Canale pubblico Forgegit tramite API release o manifesto HTTPS configurabile.
- Firma del pacchetto e della versione, rifiuto di download incompleti/manomessi,
  nessun account o contenuto delle campagne inviato al server.
- Backup `.nodex` di tutte le campagne e degli allegati gestiti; ricevuta con hash
  e preferenze. Se il backup fallisce non si avvia l’installer.
- Integrazione MCP esterna della 0.3.0 inclusa, sempre nascosta e disattiva per
  impostazione predefinita; l’assistente integrato resta escluso.

SQLite 015 e identificatore dell’archivio invariati. Runtime/pesi AI separati.
Le versioni senza updater richiedono questa prima installazione manuale;
le versioni successive possono essere installate dall’app. Riaprire al termine.

Verifiche locali e limiti di piattaforma in docs/STATUS.md; procedura e firma in
docs/UPDATES.md. Firma updater distinta da Authenticode; il canale non deve
annunciare target macOS/Linux senza averli effettivamente costruiti e verificati.
