# Chronexus 0.12.0 — Windows x64

This version adds the M31 clue board for player-authored questions, leads,
suspicions and rumours. A clue can cite a selected note block, link Codex pages,
and record how a question was resolved. Editing or resolving it does not alter
the source note or assert a factual relationship. Clues are searchable and
included in campaign backup, restore and readable export.

Sharing each clue requires an explicit choice. Its linked pages and source
sessions must be available to the same audience first. This needs a compatible
Chronexus Server with schema 007; the local board works without a server.

This package is for Windows x64 only. The NSIS installer has a production Tauri
updater signature and is available through the in-app updater with its required
backup. It has no Windows Authenticode signature, so SmartScreen may warn on first
launch. It contains no AI model weights. Windows ARM64, macOS and Linux packages
have not been built for this version.

Database schema 022 is additive. Existing campaigns, saved interface language,
notes, attachments and local AI choices are preserved. Installation and upgrade
of this exact installer are reported in the release evidence separately from
compilation and signature checks.
