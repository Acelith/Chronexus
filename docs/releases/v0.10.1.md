# Chronexus 0.10.1 — rebuilt from the GitHub source (pre-release)

Replaces the 0.10.0 pre-release. The application is the same as 0.10.0, rebuilt from the
current source now hosted on GitHub, plus the hosting move:

- **Updates and links now point to GitHub.** The in-app update check reads
  `github.com/Acelith/Chronexus` (with strict checks on GitHub's download redirects); the
  previous default channel is migrated automatically. Signed-update verification and the
  mandatory backup before installing are unchanged.
- All interface texts for the update channel are translated in the ten languages.

This is a **pre-release without signatures**: no Authenticode, no Apple Developer ID and no
updater signature, so it is **not offered by the in-app updater**: download it here. Every
file is listed with its SHA-256 in `SHA256SUMS.txt`.

| System | File | Tested |
| --- | --- | --- |
| macOS Apple Silicon | `Chronexus_0.10.1_aarch64.dmg` | See the release page |
| macOS Intel | `Chronexus_0.10.1_x64.dmg` | Built; not started (no Intel Mac available) |
| Linux ARM64 | `Chronexus_0.10.1_arm64.deb`, `Chronexus_0.10.1_aarch64.AppImage` | See the release page |
| Linux x64 | `Chronexus_0.10.1_amd64.deb` | See the release page |
| Windows x64 | `Chronexus_0.10.1_x64-setup.exe` | Built; not run (no Windows machine available) |

Not available: Windows ARM64 (the cross-build fails in a cryptography library) and the
Linux x64 AppImage (needs a native x64 build host).

**First launch of an unsigned app**
- Windows: SmartScreen → *More info* → *Run anyway*.
- macOS: right-click the app → *Open* → *Open* (ad-hoc signed, not notarized).
- Linux: install the `.deb` with your package manager, or make the AppImage executable.

**Also in this line (from 0.10.0):** campaign members (list, change role, remove, leave),
the role refreshed at every synchronization, a reader's unsent changes shown as waiting, a
valid macOS ad-hoc signature and a readable campaign picker on Linux.

**Works with** Chronexus Server 0.1.0 and 0.1.1. No schema change (021); existing archives
open as before.
