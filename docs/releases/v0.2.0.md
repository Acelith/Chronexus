# Chronexus 0.2.0 — M12, M13 and distribution M11

The two dragons react to the extreme results of a single die: they celebrate the
maximum or threaten the player on the minimum. For d100, 1 is celebrated and 100 is
threatening. Multiple rolls remain ordinary; replays and animations reuse the
saved roll without modifying it. Skips and reduced movement are available.

Settings include Espruar (Elven D&D/Forgotten Realms) and Dethek, with
original local OFL fonts, semantic text, and readable fallback. These are alphabets,
not complete translations. The laboratory preserves the original in reversible
v2 packages; previous v1 packages remain readable.

## Download and startup

For the app alone, download `Chronexus-0.2.0-Installer-Windows-x64.zip` (approximately
29 MiB), extract it, and run the setup. For app + AI, download the remaining five ZIPs instead.
Extract only `Chronexus-0.2.0-Windows-x64.zip`;
leave the four `AI-pesi-*-di-4.zip` intact next to the extracted folder.

- Run `Chronexus_0.2.0_x64-setup.exe` for the app.
- Run `Installa-AI.cmd` for the offline runtime and Gemma 4 12B.
- Start `Start-AI.ps1` in the installed AI folder, then explicitly select and
  activate the model in the campaign settings.

The README file in the first ZIP describes paths, space, and removal. The volumes are
valid separate ZIPs; they are not multi-volume archives to be opened with 7-Zip. AI
installation with SHA-256 verification and local reconstruction, without downloads or overwrites
on personal folders. Gemma 4 12B Q4_K_M is multilingual, not fine-tuned for D&D.
Only public base weights and Ollama 0.40.10 runtime: no campaign, conversation,
credential, profile, or private adapter. Licenses/fonts and notices included.

## Declared Limits

Unsigned Windows x64 package; WebView2 and GPU drivers must already
be present. No macOS or Linux build/installation verified. The release
executable was not started on the personal archive: startup/IPC verified in the
isolated debug build of the same source. Update of a pre-existing
personal installation not tested. Draft translations, native review,
OS IME and physical assistive technologies still open from M10. QLoRA training
requires separate checkpoints and dependencies, not included in the base AI package.
