# Chronexus 0.13.1 — Windows x64

A reliability update for shared campaigns and Chronexus Table.

- Every answer from the sharing server is now read with a size limit, including
  image uploads and server AI answers, so a faulty server cannot exhaust memory.
- A server AI question no longer stays pending forever when the server stops in the
  middle of its answer: it ends with an error after 15 minutes.
- After a live table connection has been stable for a minute, the next reconnection
  is fast again instead of waiting up to 30 seconds.
- Printed character sheets include skill training, inspiration, death saves and the
  details of items and abilities.
- In the session recap, pin notes with a checkbox and cancel an AI recap draft
  while it is being written.

This package is for Windows x64 only. The NSIS installer has a production Tauri
updater signature and is available through the in-app updater with its required
backup. It has no Windows Authenticode signature, so SmartScreen may warn on first
launch. It contains no AI model weights. Windows ARM64, macOS and Linux packages
have not been built for this version.

No database migration. Existing campaigns, saved interface language, notes,
attachments and local AI choices are preserved.
