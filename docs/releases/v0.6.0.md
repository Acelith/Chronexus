# Chronexus 0.6.0 — Local wiki translation

- **Translate into [app language]** in the Wikidot and Open5e entries. The first
translation requires a click; saved copies reappear even offline.
- Translation on the device with Qwen3 4b-instruct already installed, Ollama without
cloud and available GPU. No automatic downloads and no campaign data
sent to the model or to external services.
- Original always consultable; source, edition, and license preserved. The
translations are automatic drafts: verify terms and rules in the original.
Klingon/Romulan maintain the original with an explicit notice.
- Undo, language change, check for incomplete responses and numbers.
Translation cache deletable with that of the relative wiki, included
in verified backups. No changes to already saved spells.

Compatibility: SQLite schema **017**, additive migration from 0.5.0. Previous
backups remain restorable; previous versions do not read the schema
017. The internal update verifies the signature and creates the mandatory backup.
Runtime and AI weights remain separate from the app installer.

Windows x64. Verified local Italian/German/Arabic translation, cache without
runtime, undo, and view accessibility. Other languages and terminology
require review; macOS/Linux and personal installation not tested.
The updater signature is distinct from Authenticode. Details in docs/STATUS.md and
docs/WIKI_TRANSLATION.md. M18 remains planned separately.
