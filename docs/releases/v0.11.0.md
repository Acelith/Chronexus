# Chronexus 0.11.0 — Windows x64

This Windows release adds an explicit choice of where a campaign's assistant runs:
on this computer (the existing default) or on its sharing server. The server is
contacted for AI only when you check its available models or ask a question. The
server must have a compatible AI service and a qualified model installed; selecting
this option does not install or activate one. Failed requests explain the problem
and offer an explicit return to local AI. Campaign data is never sent to the server
AI by merely opening the app or choosing a setting.

The release also includes the updated German, French and Spanish interface text,
and a test that checks ordinary app startup does not open a server connection.
The app continues to use the GitHub update channel introduced in 0.10.1.

This package is for Windows x64 only. The NSIS installer has a production Tauri
updater signature and is available through the in-app updater with its required
backup. It has no Windows Authenticode signature, so SmartScreen may warn on first
launch. It contains no AI model weights. The 0.10.1 macOS and Linux pre-release
packages remain available; this release does not claim a build for those systems
or Windows ARM64.

The database remains at schema 021. Existing campaign settings default to the
local assistant. Server AI requires a compatible Chronexus Server deployment;
model quality and a live question against a server with real weights are not yet
verified. Installation and upgrade checks for this exact installer are reported
in the release evidence separately from compilation and signature checks.
